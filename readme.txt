== Description ==

Post Link Drop allows you to import your Instagram posts and create a customizable image grid on your WordPress site. Perfect for "link in bio" style landing pages.

Features:

* Import posts from Instagram automatically
* Locally host images in your WordPress media library
* Assign destination URLs to each grid item
* Display a responsive image grid using a shortcode
* Manage grid items with status controls (linked, unlinked, hidden)

== Installation ==

1. Upload the `post-link-drop` folder to the `/wp-content/plugins/` directory.
1. Activate the plugin through the 'Plugins' menu in WordPress.
1. Navigate to Post Link Drop > Settings to connect your Instagram account.
1. Use the `[link_drop]` shortcode to display the grid on any page.
